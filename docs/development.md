# Development

## Checks

From the repository root:

```
.venv/Scripts/python -m pytest
.venv/Scripts/python -m ruff check .
.venv/Scripts/python -m ruff format --check .
.venv/Scripts/python -m mypy
```

From `web/`. The tests run TypeScript directly, which takes Node 22.18 or later:

```
npm run build
node --test 'src/**/*.test.ts'
```

## Loom

The files in `web/src/components/loom/` are generated by [Loom](https://github.com/ikolajm/loom) and are not edited by hand. `npm run loom:sync`, from `web/`, regenerates them from `loom-answers.json`, and needs a Loom checkout beside this repository.
